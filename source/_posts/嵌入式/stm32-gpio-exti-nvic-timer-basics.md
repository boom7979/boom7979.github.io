STM32 既需要响应外部按键等信号，也需要周期性执行任务。本文从 GPIO、EXTI、NVIC 的中断链路出发，建立 TIM 定时器的基本概念，并推导 PSC、ARR 与定时周期的关系。以下为对话中的**理论学习笔记**，不是实物测试记录。

## 核心概念

| 缩写 | 名称 | 作用与记忆 |
| --- | --- | --- |
| GPIO | General Purpose Input/Output | 通用输入输出，读取或输出数字电平 |
| EXTI | External Interrupt/Event Controller | 检测配置的外部边沿，产生中断/事件请求 |
| NVIC | Nested Vectored Interrupt Controller | 对中断使能、优先级及异常响应进行管理 |
| TIM | Timer | 定时器硬件外设，可按时钟节拍计数 |
| PSC | Prescaler | 预分频：决定 CNT 数得多快 |
| ARR | Auto-Reload Register | 自动重装载：设定一轮计数长度 |
| CNT | Counter | 当前计数器数值（后续课程进一步学习） |

## 工作原理

### GPIO → EXTI → NVIC → 中断服务函数

以 PA0 接上拉按键为例：松开时为高电平，按下接地后变为低电平；按下动作对应**下降沿**。将 PA0 映射至 EXTI0，并选择下降沿触发后，基本过程为：

```text
按键按下，PA0 从高变低
        ↓
GPIO 输入电平变化
        ↓
EXTI0 识别下降沿并置位挂起标志
        ↓
NVIC 判断使能与优先级
        ↓
CPU 响应，进入 EXTI0_IRQHandler()
        ↓
处理事件、清除挂起标志、返回被中断的代码
```

轮询是 CPU 反复主动检查输入；中断是硬件事件请求 CPU 在适当时机处理。中断并不是无条件“立刻执行”，是否响应还受到使能、屏蔽和优先级等条件影响。

### NVIC 优先级

对于 STM32F103 常用的优先级配置，可区分：

- **抢占优先级**：是否能打断正在执行的其他可屏蔽中断。
- **子优先级（响应优先级）**：同抢占级别的多个待处理请求，决定先后顺序；它本身不能造成抢占。

**数值越小，优先级越高。** 具体可分配的位数受 NVIC 优先级分组影响。例如：EXTI0 抢占级别为 1、TIM2 为 2，则满足使能条件时 EXTI0 可抢占 TIM2；如果 EXTI0 和 USART1 抢占级别相同，仅凭子优先级不能彼此抢占。

### TIM 周期公式怎么来

先从“数数”理解，而不是死记：

1. 输入时钟频率为 $f_{TIM}$，表示**每秒有多少个输入时钟周期**。
2. `PSC + 1`：**CNT 每增加 1**，需要多少个输入时钟周期。
3. `ARR + 1`：普通向上计数模式下，**一轮需要多少个 CNT 计数节拍**。
4. 二者相乘，是一轮所需的输入时钟周期总数；每个输入时钟周期耗时 $1/f_{TIM}$。

因此：

$$
T=(PSC+1)(ARR+1)\frac{1}{f_{TIM}}
 =\frac{(PSC+1)(ARR+1)}{f_{TIM}}
$$

**我的理解（本对话中的原话整理）：** `ARR+1` 是总计数次数，`PSC+1` 是每次数数需要的输入时钟周期数，相乘就是一轮需要的输入时钟周期总数。需要纠正的一点：**$f$ 是频率，不是单个时钟周期的时间；单个时钟周期的时间是 $1/f$。**

## 示例：两组定时器周期

假设以下例子中**定时器实际输入时钟**均为 72 MHz，且为连续向上计数模式。

| 参数 | 例一 | 例二 |
| --- | ---: | ---: |
| $PSC$ | 7199 | 3599 |
| $ARR$ | 9999 | 1999 |
| 实际分频系数 | 7200 | 3600 |
| CNT 计数频率 | 10,000 Hz | 20,000 Hz |
| 每轮 CNT 节拍数 | 10,000 | 2,000 |
| 更新周期 | **1 秒** | **0.1 秒** |

例如例一：$72,000,000/(7199+1)=10,000$ 次/秒，再数 $9999+1=10,000$ 次，得到 $T=1$ 秒。

## 易混点与自检

- **PSC=7199 并不是除以 7199**，实际除以 7200。
- **ARR=9999 是数 10,000 个节拍**，因为从 0 开始。
- **CPU 主频不一定等于 TIM 输入时钟**；STM32F103 不同 APB 预分频配置会影响定时器时钟，实际应检查时钟树。
- **按键机械抖动**会造成多个边沿；上述流程只解释中断原理，不代表已经完成消抖设计。
