## 项目背景

面向深度学习视觉任务的实验与应用需求，我参与开发可视化操作平台，将模型推理、训练配置、测试评估和结果管理等命令行流程整合到统一的图形界面。

## 主要工作

- 基于 Python 和 Streamlit 开发平台的页面结构、侧边栏导航和核心功能页面。
- 负责运行环境检测、数据集路径管理、模型文件管理和配置文件管理。
- 将模型推理、训练和测试任务封装为可视化流程，支持参数配置、任务启停和运行状态查看。
- 实现实时日志查看、训练结果展示、测试指标解析和输出文件预览。
- 针对 Windows 和 GPU 深度学习环境中的路径、依赖、数据格式及参数配置问题，增加校验和异常提示。
- 将页面层与服务层分离，对配置解析、任务管理、日志读取和结果处理进行模块化封装。
- 编写项目功能说明、开发交接文档、验收范围表和测试记录，协助完成系统功能验证。

## 项目成果

- 完成视觉模型实验流程的可视化改造，减少对命令行和手动修改配置文件的依赖。
- 建立从环境检测、任务配置、任务执行到结果查看的完整操作流程。
- 规范实验任务配置，让运行过程更易追踪，结果更便于管理。

## 技术栈

Python、PyTorch、Streamlit、YAML、进程管理、GPU 加速、OpenCV。
